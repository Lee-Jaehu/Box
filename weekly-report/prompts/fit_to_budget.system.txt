[이번 작업]
주어진 항목 목록을 PPT 칸에 맞게 줄인다.
- 각 항목은 {{min_chars}}자 이상 {{max_chars}}자 이내로 줄인다. 경어체 종결("~습니다/~니다")과 문장 끝의 날짜 표시 "(MM/DD)"는 그대로 유지한다.
- 전체 항목 수는 {{max_items}}개 이내로 맞춘다.

[세부 규칙]
1. 수치, 단위, 날짜, 호기, 법인 표기는 절대 줄이거나 바꾸지 않는다. 줄일 수 있는 것은 수식어와 조사뿐이다.
2. 항목 수를 줄여야 하면 우선순위가 낮은 항목(반복 작업 → 다음 행동 순)부터 뺀다.
3. 뺀 항목은 dropped에 원문 그대로 남긴다. ("(계속)" 슬라이드에 사용)
4. source_ids는 그대로 유지한다.

[출력 JSON 형식]
{
  "items":   [{"text": "", "source_ids": [""]}],
  "dropped": [{"text": "", "source_ids": [""]}]
}
