# UI 재설계: Claude × Codex 토론 기록 (2026-11-18)

사용자 요청: 직수만 추가, 복잡함 줄이기, 탭을 직관적으로, 아이콘·그림 사용. 이후 "토스 같은 스타일" 추가.
방식: Codex CLI(ChatGPT 계정 로그인)에게 앱 코드·화면 캡처만 담은 폴더를 주고 라운드마다 의견 파일을 받았다. Codex는 코드를 고치지 않았고 구현은 Claude가 했다.

## Codex가 찾고 고친 버그

| 버그 | 재현 | 수정 |
|---|---|---|
| 유축량 수정 시 재고 두 배 | 100ml 저장 후 '고치기' 재저장 → 200ml | 연결된 팩을 고친 만큼만 갱신, NICU 배송 기록도 함께 |
| 유축만도 '마지막 수유'로 표시 | 유축만 끝내면 마지막 수유 갱신 | 딸 직수·젖병만 기준 |
| 젖병 기록량 ≠ 차감량 | 100ml 팩에서 60ml → 팩 전체 소진 | 남은 양은 해동 상태로 재고에 남김, 모자라면 다음 팩 |
| 젖병 기본값이 그대로 기록 | 열자마자 저장 → 권장값이 기록 | 종류·양을 직접 골라야 저장 |
| 저장 실패 시 입력 유실 | 권한 오류에도 시트 닫힘 | 성공 시에만 닫기, 같은 id로 재시도 |
| 기기 저장 실패에도 성공 표시 | localStorage 예외 무시 | 오류 문구 표시 |
| 재시도 시 두 번 차감 | 저장 실패 후 재시도 → 남은 양까지 소진 | 첫 클릭에 차감 계획 고정, 저장 중 잠금 |
| 초기 모유가 딸 젖병에서 차감 | 추가 팩 고를 때 제한 누락 | 생후 14일까지 짠 아들 전용 모유는 차감 대상에서 제외 |
| 중간 실패 후 불일치 | 기록만 저장되고 팩 차감 실패 | 차감 계획을 기록 안에 저장, 다음에 열 때 마저 반영 |

각 수정은 브라우저 재현 스크립트로 확인했다. 계산 로직 테스트 20개 통과.

## 토스 스타일 적용
- 가져온 것: 회색 바탕 위 흰 카드, 화면마다 큰 한 문장 제목("할 일이 4개 있어요", "모유 510ml를 보관 중이에요"), 왼쪽 둥근 아이콘 + 오른쪽 값의 목록, 하단 전폭 주 버튼, '~했어요' 알림.
- 바꾼 것: 야간 화면은 호박색, 엄지가 닿는 아래에 시작·기록 버튼, 터치 영역 44px 이상, 긴급 연락은 접지 않고 펼쳐 둠.
- 가져오지 않은 것: 토스 로고·전용 폰트·브랜드 그대로 복제.
