# 신생아 위험 기준 검토 (2026-11-22, 생후 16일)

기능 목록이 아니라 **생후 1~2개월에 실제로 아기를 다치게 하는 것** 순서로 앱을 다시 봤습니다.

**받은 원자료**
- 아직 없음: 새벽 "모르겠는 순간" 일지, 잠자리 설명, 퇴원요약지, 모자보건수첩, 부모 수면 시간
- 있는 것: 앱 기록(수유·잠·울음), 1차 지침

그래서 "우리 집 가능성" 칸은 원자료를 받으면 고칠 **가정값**입니다.

## 2. 위험을 가장 많이 줄이는 기능 3개

### (a) 밤 수유 중 안전한 잠

- **줄이는 위험:** 소파·안락의자·침대에서 아기를 안은 채 잠드는 것. AAP 2022는 이것을 가장 위험한 잠자리로 꼽고, 쌍둥이를 한 잠자리에 함께 재우지 말라고 권고합니다.
- **쓰는 신호:** 현재 시각(21~07시), 직수 진행 중, 시작 후 경과 시간

| 언제 | 어디서 | 문구 (원문) |
|---|---|---|
| 직수 25분 넘음 (밤) | 엄마 수유 화면 | "졸리면 먼저 아기를 아기 침대에. 소파·의자에서 아기를 안고 잠드는 게 가장 위험해요. 잠들었다 깨면 바로 아기 자리로." |
| 직수 30분 넘음 (밤) | 아빠 할 일 (빨간 배너), 대기 모드면 소리·진동 1회. 아빠 수면 시간엔 무음 | "엄마 수유가 30분 넘었어요. 아기를 안고 잠들지 않았는지 봐 주세요." |
| 밤에 수유 끝 | 시리 응답 (엄마 화면을 안 봐도 들림) | "…끝. 8분이에요. 등 대고, 아기 침대로." 30분 넘었으면 "오래 안고 있었어요. 아기는 등 대고 자기 침대로." |
| 잠 시작 | 시리 응답 | "잠들었어요. 등 대고, 자기 잠자리에 아기만 있는지 봐 주세요." |
| 처음 한 번 (끝날 때까지 할 일) | 아빠 할 일 → 점검 시트 | 7가지: 두 아이 각자 잠자리 / 항상 등 / 단단하고 평평 / 잠자리엔 아기만 / 같은 방 다른 잠자리 / 소파에서 졸리면 먼저 눕히기 / 덥지 않게 |

- **손 안 쓰고:** 시리 응답은 에어팟으로 들립니다. 화면 안내는 페이지가 열려 있을 때만 보입니다.
- **한계:** 엄마 화면이 꺼져 있고 아빠가 자는 시간에는 앱이 막지 못합니다. 그래서 실제 방어선은 **잠자리 점검**입니다. 졸릴 것 같은 밤에는 소파가 아니라 쿠션을 치운 침대에서 수유하고, 깨면 바로 아기를 자기 자리로 옮깁니다.

### (b) 아기가 울 때

- **줄이는 위험:** 지친 부모가 우는 아기를 흔드는 것, 열이나 응급 신호를 놓치는 것
- **쓰는 신호**
  - 울음 기록(사운드 인식 자동 또는 "시리야, 아기 울어")이 30분 안에 이어지고 그 사이 '그침'이 없으면 한 번의 울음으로 봅니다.
  - 마지막 수유, 마지막 기저귀, 깬 시간

**구성**
- **'울 때' 버튼:** 모든 화면 위쪽에 있고 한 번 누르면 열립니다.
- **확인 순서 6단계:** 배고픔(마지막 수유 ○분 전) → 기저귀 → **체온 (38.0℃ 이상이면 바로 응급실)** → 덥거나 춥지 않은지 → 트림 → 졸림(깬 지 ○분)
- **"그래도 안 그치고 내가 지치면"**
  - "아기를 등 대고 아기 침대에 눕히고 방을 나와 5~10분 쉬어도 괜찮아요. 우는 건 아기를 다치게 하지 않지만, 흔들면 크게 다칠 수 있어요. 쉬는 동안 배우자를 깨우거나 누군가에게 전화하세요."
  - 10분 쉬기 버튼: '쉬기' 기록과 함께 타이머가 돌고, 끝나면 진동으로 알립니다.
- **"이럴 땐 바로 119·응급실":** 38.0℃ 이상 · 축 처지고 깨워도 잘 안 깸 · 숨쉬기 힘들거나 입술이 파래짐 · 초록색 구토 · 날카로운 울음이 계속되고 먹지 않음
- **'그쳤어요' 기록:** 먹여서 / 기저귀 / 재워서 / 안아줘서 / 모름
- **시리**
  - 20분 넘게 울면 "아기 울어"의 응답이 바뀝니다: "○분째 울고 있어요. 먹이기, 기저귀, 체온, 트림을 봤는데도 안 그치면 아기를 등 대고 침대에 눕히고 5분에서 10분 쉬어도 괜찮아요. 흔들지는 마세요. 38도 이상이거나 축 처지면 바로 응급실이에요."
  - 새 단축어 **"잠시 쉬기"** = 시계 앱 10분 타이머 + 서버 기록 + "아기를 등 대고 침대에 눕혔으면 방을 나와 숨을 고르세요. 10분 뒤에 다시 보러 가요."
- **근거 메모:** 울음 교육 프로그램(PURPLE) 자체의 효과 연구는 엇갈립니다. 그래서 프로그램을 내세우지 않고, CDC가 권하는 행동(안전한 곳에 눕히고 5~10분마다 확인, 도움 요청)만 씁니다.

### (c) 두 아이 검진·접종 일정

- **줄이는 위험:** 두 벌의 일정 중 누락, 아들의 NICU 일정과 집 일정이 섞이는 것
- **쓰는 신호:** 출생일(11/6) 하나로 날짜를 계산하고, '검진·접종 기록(care)'으로 완료·NICU·정상 확인을 표시합니다.

| 항목 | 앱이 계산한 기간 | 비고 |
|---|---|---|
| B형간염 1차 | 11/6 (출생 시) | 병원에서 함 → 퇴원요약지로 '확인' |
| 선천성대사이상검사 결과 | 11/8 ~ 11/20 | 병원 채혈 → 결과 '정상 확인' |
| 신생아 청각선별검사 | ~ 12/6 | 보통 출산 병원에서. 재검이면 3개월 안 정밀검사 |
| **영유아건강검진 1차** | **11/20 ~ 12/11 (지금 가능)** | 키·몸무게·머리둘레. 기간 안이면 본인부담 없음 |
| **BCG (피내용)** | **~ 12/10 (34일까지)** | B형간염 2차와 같은 날 권장. 아들은 NICU에 시기 문의 |
| B형간염 2차 | 12/6 ~ | 생후 1개월 |
| 2개월 접종 | 1/6 ~ | DTaP·폴리오·Hib·폐렴구균·로타. 백신 종류·간격은 예방접종도우미 확인 |
| 영유아건강검진 2차 | 3/6 ~ 5/6 | |

- **화면:** 아이들 탭 카드에 항목마다 [딸 상태][아들 상태]가 나오고, 누르면 '했어요' / 'NICU에서 했어요' / '결과 정상' / 되돌리기를 고릅니다. 할 일에는 가장 급한 1건과 나머지 개수만 한 줄로 나옵니다.
- **시리:** "시리야, 검진 일정" → "영유아건강검진 1차 12월 11일까지. BCG 결핵 접종 12월 10일까지…"
- **한계:** 정해진 일정만 보여줍니다. 실제 접종 판단은 의료진이 하고, 아들은 NICU가 정합니다.

## 3. 성장: 키·머리둘레

**결정: 검진 때만 적는 칸으로 넣었습니다.**
- 체중 기록 화면에 키·머리둘레 칸을 추가했고, 선택 입력입니다.
- 이유: 소아과는 체중·키·머리둘레 세 가지로 성장을 봅니다. 1차 영유아건강검진에서 이 셋을 잽니다.
- 하지만 집에서 줄자로 재면 오차가 커서, 매일 기록하는 건 의미가 없습니다.
- 백분위는 앱이 계산하지 않고, 검진 결과지나 질병관리청 성장 계산기로 봅니다. 키·머리둘레 표를 기억에 의존해 넣으면 틀릴 위험이 있어서입니다.

**NICU에 확인할 질문 (수술과 NICU 입원 때문에)**
1. 배 수술 후 **엎드려 놀기(터미타임)**는 언제부터 시작해도 되나요? 깨어 있을 때 하는 것도 기다려야 하나요?
2. NICU에서 엎드려 재운 적이 있다면, 집에서는 **언제부터 등으로만** 재우면 되나요? (AAP: 상태가 안정되면 퇴원 전부터 등으로)
3. NICU에서 맞은 접종과 날짜: B형간염 1·2차, **BCG를 언제 맞나요** (생후 34일 = 12/10 이후 일정), 2개월 접종을 NICU에서 하나요?
4. **로타바이러스 1차**는 NICU에서 맞나요, 퇴원 후인가요? 맞을 수 있는 최대 나이 안에 맞을 수 있나요? (최대 나이는 예방접종도우미 확인)
5. 청각선별검사와 선천성대사이상검사 결과
6. 퇴원 후 응급 신호(초록색 구토, 배 팽만, 혈변)와 연락할 곳 (수술 병원, 야간 번호)
7. 퇴원 후 첫 외래 날짜와 체중 증가 목표

## 4. 넣지 않은 기능과 이유

| 기능 | 이유 |
|---|---|
| 발달 이정표 알림 ("○주엔 ○를 해요") | 생후 2주에는 판단에 쓸 이정표가 거의 없음. 쌍둥이를 서로 비교하게 만들어 불안만 키움. 발달 평가는 영유아건강검진에서 |
| 울음 AI·얼굴 분석 | 집에서 검증된 방법이 없고 잘못 안심시키는 위험이 큼 (설계서 handsfree-plan 4장) |
| 원더윅스 | 근거가 약하고, 출산예정일 기준이라 실제 기록과 안 맞음 (book-vs-twins) |
| 일반 육아 정보 피드 | 새벽에 필요한 건 정보가 아니라 순서와 연락 기준 |
| 산소포화도 양말 같은 가정용 모니터 연동 | AAP 2022는 영아돌연사 예방 목적으로 가정용 심폐 모니터를 권하지 않음. 잘못된 안심을 줄 수 있음 |
| 수면 훈련·스케줄 | 생후 16일에는 해당 없음 |
| 아기 체온 매일 기록 | 열은 기록보다 즉시 행동(38.0℃ → 응급실)이 중요. '울 때' 시트에 기준만 둠 |
| 아빠 우울 점검 기능 | 필요성은 있음 (아빠 산후우울은 드물지 않음). 하지만 기능보다 두 분이 매주 K-EPDS를 서로 해보는 것으로 충분. 원하시면 엄마 상태 기록을 아빠도 쓸 수 있게 열 수 있음 |

## 5. 검증

### 5-1. 새벽 3시 시나리오 5개

| 시나리오 | 바꾸기 전 앱 | 바뀐 앱 | 남는 한계 |
|---|---|---|---|
| 딸이 30분째 울고, 엄마 혼자 | 울음 원인 순위만 말함 | 20분부터 시리가 순서·쉬기·연락 기준을 말함. '울 때' 시트, 10분 쉬기 | 사운드 인식이 울음을 못 들으면 "아기 울어"를 직접 말해야 함 |
| 엄마가 수유하다 졸고 있음 | 아무것도 없음 | 25분 엄마 화면, 30분 아빠 알림(대기 모드), 끝날 때 "등 대고 아기 침대로" | 화면이 꺼져 있고 아빠도 자면 못 막음 → 잠자리 점검이 방어선 |
| 딸 체온 37.9℃ | 문서에만 기준 | '울 때' 3단계에 38.0℃ 기준. 37.9면 30분 뒤 다시 재기는 소아과에 확인할 질문 | 체온은 앱이 모름 |
| 수유 직후 토함 (아들 퇴원 후) | 문서에만 | '바로 119'에 초록색 구토 | 퇴원 교육 내용으로 문구를 다시 맞춰야 함 |
| 배고픈지 졸린지 모르겠음 | 원인 순위 | 시트 1·6단계에 마지막 수유 ○분 전, 깬 지 ○분 | 잠을 기록하지 않으면 깬 시간은 모름 |

### 5-2. 소아과·보건소에 보여줄 안전 문구 1장
`docs/safety-sheet.pdf`를 1차 영유아건강검진(11/20~12/11)에 들고 가서 확인받습니다. 고칠 문구가 있으면 앱 문구도 같이 고칩니다.

### 5-3. 공식 일정과 날짜 대조
위 2-(c) 표의 날짜를 예방접종도우미(nip.kdca.go.kr, 두 아이 등록 후)와 모자보건수첩의 날짜와 비교합니다. 한 칸이라도 다르면 공식 날짜를 따르고 앱을 고칩니다.
