# 수유 책 가이드 × 우리 쌍둥이 (2026-11-19 반영)

참고한 자료
- 수유 책 62~73쪽 사진 (똑게육아 수유 비법 노트, 수유량 계산, 월령표, 몸무게 백분위표, 원더윅스, 모유수유 경험담)
- 질병관리청 2017 소아청소년 성장도표: 36개월 미만은 WHO 성장기준을 씀. 2027 성장도표가 나오기 전까지 현행.
  - 질병관리청 누리집(kdca.go.kr, health.kdca.go.kr)은 이 작업 환경에서 접속이 막혀 있어서, 질병관리청 안내를 인용한 2차 자료로 확인했습니다 (아래 출처).
  - 책의 백분위표 값은 WHO 성장기준 값과 같습니다.

## 앱에 넣은 것

| 책 내용 | 앱에서 | 쌍둥이라 바꾼 점 |
|---|---|---|
| 하루 수유량 = 몸무게 × 120~150ml, 하루 1,000ml 넘지 않게 (63·64쪽) | 아이들 탭 '딸 수유 가이드': 지금 체중으로 하루 기준량 (2.80kg → 336~420ml) | 양은 월령이 아니라 **지금 체중**으로 계산. 엄마 공급 목표는 두 아이 합 (아들은 완전수유 기준) |
| 1회 수유량 월령표: 2주 ~80ml, 6주 ~120ml… (65·67쪽) | '젖병 1회 참고량' = 하루 양 ÷ 8~12회 (지금 28~53ml). 젖병 시트에도 표시 | 책 표는 평균 3.6~3.8kg 아기 기준. 2.6kg대로 태어난 우리 아이에게 그대로 쓰면 많음. 책의 해당 줄을 같이 보여주고 차이를 설명 |
| 수유텀 = 시작부터 다음 시작까지 (64쪽) | 타임라인 간격 알약, 가이드의 수유텀 중앙값 | 같은 정의 그대로 |
| 수유텀에 강박 갖지 말 것 (62쪽) | 간격은 알림 없이 보여주기만 함. 연락 기준(소아과 확인 전 기본값)만 알림 | 37주 출생이라 너무 긴 간격(기본 4시간)만 당일 연락 기준으로 남김 (ABM #10) |
| 한쪽 10~15분, 아기마다 다름 (62쪽) | '한쪽 평균 수유 시간' (쪽 바꾸기 기록에서 계산) | 평균 8분 미만이면 "IBCLC에 직수 효율을 물어보세요"를 안내. 진단하지 않음 |
| 수유 전후 체중으로 먹은 양 보기 (68쪽, 3.5→3.6kg = 약 100ml) | 기록 탭에서 직수 기록 → '수유 전후 체중 적기' → 타임라인·가이드에 '먹은 양 약 34ml' | 아기를 안고 어른 체중계로 재는 방법은 100g 단위 오차라 신생아에게 맞지 않음. 2~10g 단위 신생아 체중계를 쓰도록 안내 |
| 체중은 한 달 600~900g, 6개월까지 하루 20~30g (66쪽) | '체중 증가' 7일 기울기 옆에 책 기준 표시 | 연락 기준(최소 g/일)은 소아과와 정해서 설정에 넣음 (지금은 꺼둠) |
| 몸무게 백분위표, 질병관리청 성장 계산기 (66·67쪽) | 아이별 성장 그래프에 백분위 띠(1·25·50·75·99), "1~25백분위 · 출생 때 1~25백분위" | 두 아이 모두 작게 태어나 낮은 띠에서 시작. **출생 때와 같은 띠를 따라가는지**를 봄 (평균선과 비교하지 않음) |
| 밤수 때 한 번은 유축 젖병 연습 (62쪽) | 이미 아빠 밤 교대 젖병(배분 규칙 2)으로 하고 있음 | 아들 퇴원 뒤엔 한 명은 엄마 직수, 한 명은 아빠 젖병으로 동시에 먹이는 데 쓰임 |
| 비상시 대비 유축 (63쪽) | 냉동 비축·NICU 배송 (모유 탭) | 아들 몫이 먼저라 '비상용'이 아니라 매일의 공급 |
| 유두 상처, 젖몸살, 유선염 (72·73쪽) | 엄마 몸 상태 기록(통증·체온·뭉침) → 연락 기준 | 기존 그대로. 유선염 대응은 ABM #36 (강한 마사지·과도한 유축 금지) |

## 넣지 않은 것

- **원더윅스 체크차트 (69쪽)**
  - 아기 뇌 발달의 '도약 시기'를 주 단위로 정한 표인데, 이를 뒷받침하는 연구 근거가 약합니다.
  - 쓰더라도 출산예정일(37주 출생이므로 약 11/27) 기준으로 세야 해서, 실제 기록과 맞추기 어렵습니다.
  - 보채는 날이 있으면 원더윅스로 해석하기보다, 연락 기준표(열·처짐·소변 감소 등)를 먼저 봅니다.
- **2개월 이후 월령표의 횟수 줄이기 (7~9회, 6~8회…)**
  - 아직 생후 13일입니다. 두 아이의 체중 곡선과 소아과 판단에 따라 그때 다시 정합니다.

## 쌍둥이라서 특히 다른 점 (정리)

1. **작게 태어남:** 2.63·2.64kg으로 책의 평균 아기(3.2~3.3kg)보다 작습니다. 월령표 대신 체중 기반으로 계산하고, 백분위는 평균이 아니라 자기 띠를 따라가는지 봅니다.
2. **37주 출생:** 성장도표는 실제 나이로 봅니다. 교정 나이는 보통 37주 미만 출생에 쓰니 소아과에 확인합니다. 졸려서 짧게 먹을 수 있어서, 너무 긴 간격과 짧은 수유를 지켜봅니다.
3. **엄마 모유는 두 아이 몫:** 딸 직수 + 아들 유축이 같은 공급에서 나갑니다. 책의 한 아이 기준을 두 번 더한 양이 엄마의 목표입니다.
4. **아들은 NICU 처방이 기준:** 책 가이드를 아들 수유량에 쓰지 않습니다.
5. **다태아 엄마는 모유수유 취약군:** 국내 연구에서 단태아와 같은 교육으로는 실천률이 오르지 않았습니다. 그래서 이 앱의 핵심은 정보보다 **아빠 분업과 손 안 쓰는 기록**입니다.
