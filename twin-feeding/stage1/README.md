# 1단계 설치: 시리·액션 버튼·잠금화면으로 기록하기

준비물: 두 아이폰, 구글 계정 1개, (권장) PC 또는 노트북 1대
- 코드 붙여넣기는 PC가 훨씬 편합니다. 폰만 있다면 사파리에서 '데스크톱 웹사이트 요청'으로 할 수 있습니다.
- NFC 스티커(NTAG213)는 선택입니다. 인터넷에서 개당 몇백 원입니다.

---

## 0. 구글 계정 정하기 (지금 막혀 있는 부분)

지금 연결된 구글 계정은 **드라이브 용량이 꽉 차서 새 시트를 만들 수 없습니다.** 둘 중 하나를 골라 주세요.

- **A. 지금 계정 공간 비우기:** 드라이브 휴지통 비우기, 큰 파일 정리. 시트 하나는 몇 KB입니다.
- **B. 육아 전용 구글 계정 새로 만들기:** 무료 15GB. 기록이 개인 메일·사진과 섞이지 않고, 나중에 아내에게 계정을 넘기기도 쉽습니다.

## 1. 시트와 서버 만들기 (PC로 10분)

1. 고른 계정으로 `sheets.new`를 엽니다.
   - 이름은 **쌍둥이 수유 기록**으로 합니다.
   - 주소창의 `/d/`와 `/edit` 사이 긴 문자열이 **시트 ID**입니다. 메모해 둡니다.
2. 시트 메뉴 **확장 프로그램 > Apps Script**를 엽니다.
3. 파일 세 개를 만듭니다.
   - `Code.gs`: 처음 있는 내용을 지우고 이 폴더의 `gas/Code.gs`를 붙여넣습니다. 맨 위 `'__SHEET_ID__'`를 1번의 시트 ID로 바꿉니다.
   - **+ > 스크립트** → 이름 `Migrate`: `gas/Migrate.gs`를 붙여넣습니다. (기존 기록 13건 옮기기)
   - **+ > HTML** → 이름 `Index`: `gas/Index.html`을 붙여넣습니다. (웹 화면, 약 120KB)
4. 왼쪽 **프로젝트 설정(톱니바퀴)**에서 시간대를 **(GMT+09:00) 서울**로 합니다.
5. 위쪽 함수 목록에서 `setup`을 고르고 **실행**합니다.
   - 권한 요청이 나오면 계정을 고르고 '고급 > 이동'으로 허용합니다.
   - 내가 만든 스크립트라서 '확인되지 않은 앱' 경고가 뜨는 것이 정상입니다.
   - **실행 로그에 나온 토큰**을 메모합니다.
6. 함수 목록에서 `migrate`를 고르고 **실행**합니다. 로그에 "13건 옮겼어요"가 나오면 성공입니다.
7. **배포 > 새 배포 > 유형: 웹 앱**으로 배포합니다.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포를 누르면 나오는 **웹 앱 URL**(…/exec)을 복사합니다.
8. **기록 주소 = 웹 앱 URL + `?k=` + 토큰**입니다. 예: `https://script.google.com/macros/s/AKfy…/exec?k=3f9a…`
   - 이 주소를 아는 사람은 기록을 보고 쓸 수 있으니 가족에게만 줍니다.

## 2. 두 폰에 웹 화면 넣기

1. 각 폰의 사파리에서 **기록 주소**를 엽니다.
2. 공유 버튼 > **홈 화면에 추가**를 누릅니다.
3. 처음 열 때 "엄마예요 / 아빠예요"를 고릅니다.
4. 아빠 폰 설정(톱니)에서 '단축어에 넣을 주소'가 기록 주소와 같은지 확인합니다.

## 3. 단축어 만들기 (아빠 폰에서 먼저)

### 3-1. 기본 단축어 하나: `수유기록 보내기`

주소는 이 단축어 한 곳에만 넣습니다. 다른 단축어는 동작 이름만 이 단축어에 넘깁니다.

| 순서 | 동작 | 설정 |
|---|---|---|
| 1 | 텍스트 | `기록주소&by=dad` (아내 폰에서는 `by=mom`) |
| 2 | 텍스트 | 1번 결과 + `&` + **단축어 입력** |
| 3 | URL의 콘텐츠 가져오기 | URL: 2번 결과, 방법: GET |
| 4 | 텍스트 말하기 | 3번 결과 (에어팟이 연결돼 있으면 에어팟으로 나옴) |

- 단축어 정보(ⓘ)에서 '공유 시트에 보기'는 끄고, **'잠겨 있을 때 실행 허용'** 항목이 보이면 켭니다.
- **설정(Setup) > 새 질문 추가**: 1번 텍스트에 "이 폰의 기록 주소(끝이 by=mom 또는 by=dad)"라는 질문을 겁니다. 아내가 받을 때 자기 값을 넣게 됩니다.
- 아기가 자는 방에서 스피커로 말하는 게 걱정되면, 4번을 **기기 진동**으로 바꿀 수 있습니다. 이 동작은 기기에서 있는지 확인이 필요합니다.

### 3-2. 말로 부르는 단축어

각각 **[텍스트] → [단축어 실행: 수유기록 보내기, 입력=텍스트]** 두 동작입니다. **단축어 이름이 곧 시리에게 말할 문장**입니다.

| 단축어 이름 (= 시리에게 말하기) | 텍스트 | 엄마 | 아빠 |
|---|---|---|---|
| 수유 버튼 *(액션 버튼용)* | `a=feed&src=action` | ✓ | |
| 왼쪽 직수 | `a=start&kind=nurse&side=L&src=siri` | ✓ | |
| 오른쪽 직수 | `a=start&kind=nurse&side=R&src=siri` | ✓ | |
| 직수 유축 | `a=start&kind=both&src=siri` | ✓ | |
| 유축 시작 | `a=start&kind=pump&src=siri` | ✓ | ✓ |
| 수유 끝 | `a=end&src=siri` | ✓ | ✓ |
| 반대쪽 *(직수 중 쪽 바꾸기)* | `a=switch&src=siri` | ✓ | |
| 기저귀 소변 | `a=diaper&wet=1&src=siri` | ✓ | ✓ |
| 기저귀 대변 | `a=diaper&stool=1&src=siri` | ✓ | ✓ |
| 기저귀 둘다 | `a=diaper&wet=1&stool=1&src=siri` | ✓ | ✓ |
| 아기 잠 *(한 번 = 잠듦, 다시 = 깸)* | `a=sleep&src=siri` | ✓ | ✓ |
| 아기 울어 | `a=cry&src=siri` | ✓ | ✓ |
| 수유 상황 | `a=status&src=siri` | ✓ | ✓ |
| 검진 일정 | `a=care&src=siri` | ✓ | ✓ |
| 방금 취소 | `a=undo&src=siri` | ✓ | ✓ |
| 뒷면 수유 끝 *(뒷면 탭용)* | `a=end&src=backtap` | ✓ | |
| 뒷면 소변 *(뒷면 탭용)* | `a=diaper&wet=1&src=backtap` | ✓ | ✓ |

질문이 들어가는 두 개는 이렇게 만듭니다.

- **젖병 기록**
  1. [메뉴에서 선택: "모유", "분유"] → 각 경우에 [텍스트 `ebm`] / [텍스트 `formula`]
  2. [숫자 묻기: "몇 밀리?"]
  3. [텍스트 `a=bottle&milk=`(메뉴 결과)`&ml=`(숫자)`&src=siri`]
  4. [단축어 실행]
  - 시리로 부르면 "모유? 분유?"와 "몇 밀리?"를 소리로 묻고, 말로 대답하면 됩니다.
- **잠시 쉬기** (울음이 안 그치고 지칠 때)
  1. [타이머 시작: 10분] (시계 앱 동작)
  2. [텍스트 `a=break&src=siri`]
  3. [단축어 실행]
  - 시리가 "아기를 등 대고 침대에 눕혔으면 방을 나와 숨을 고르세요. 10분 뒤에 다시 보러 가요."라고 말하고, 10분 뒤 시계 앱이 울립니다.
- **울음 그침**
  1. [메뉴에서 선택: 먹임 / 기저귀 / 재움 / 안아줌 / 모름] → 각 경우에 텍스트 `a=calm&how=feed` / `diaper` / `sleep` / `hold` / `unknown`
  2. [단축어 실행]

워치에서도 쓰려면 각 단축어 정보에서 **'Apple Watch에서 보기'**를 켭니다.

### 3-3. 아내 폰으로 보내기

1. 아빠 폰 단축어 앱에서 각 단축어를 길게 누릅니다.
2. 공유 > **iCloud 링크 복사**를 누르고, 링크들을 메시지 하나에 모아 보냅니다.
3. 아내 폰에서 링크를 하나씩 눌러 **단축어 추가**를 합니다.
   - `수유기록 보내기`를 추가할 때 질문이 나오면 아빠 주소의 `by=dad`를 **`by=mom`**으로 바꿔 넣습니다.
4. 엄마 표의 ✓ 단축어만 보내면 됩니다. 젖병 기록은 빼도 됩니다.

## 4. 기기별 연결 (각 폰에서)

| 어디에 | 어떻게 | 엄마 폰 | 아빠 폰 |
|---|---|---|---|
| 액션 버튼 | 설정 > 액션 버튼 > 단축어 | **수유 버튼** | 기저귀 소변 |
| 뒷면 탭 | 설정 > 손쉬운 사용 > 터치 > 뒷면 탭 | 두 번: 반대쪽(쪽 바꾸기), 세 번: 뒷면 소변 | 세 번: 뒷면 소변 |
| 잠금화면 컨트롤 | 잠금화면 길게 누르기 > 사용자화 > 잠금 화면 > 아래 버튼 > 단축어 | 수유 버튼, 기저귀 소변 | 기저귀 소변, 수유 상황 |
| 워치 | 워치 페이스 편집 > 컴플리케이션 > 단축어 | 수유 버튼 | 기저귀 소변 |

**NFC 스티커 (자동화)**
- 단축어 > 자동화 > + > NFC로 스티커를 읽힌 뒤, 동작에 [텍스트] + [단축어 실행: 수유기록 보내기]를 넣고 **즉시 실행**을 켭니다.
- 유축기 스티커: `a=feed&kind=pump&src=nfc` (한 번 대면 시작, 다시 대면 끝)
- 기저귀대 스티커 2개: `a=diaper&wet=1&src=nfc` / `a=diaper&stool=1&src=nfc`

**울음 자동 기록**
1. 설정 > 손쉬운 사용 > **사운드 인식** 켜기 > 소리 목록에서 **아기 울음**을 켭니다.
2. 단축어 > 자동화 > + > **사운드 인식** > 아기 울음 > 동작은 [단축어 실행: 아기 울어] > **즉시 실행**을 켭니다.
- 사운드 인식은 위급 상황에 의존하면 안 됩니다. 아기 상태 판단은 위험 신호 기준표대로 합니다.

## 5. 기기 시험 (폰마다 10분, 꼭 하기)

애플 문서는 잠긴 상태에서 끝까지 실행된다고 단정하지 않습니다. 그래서 **두 분 폰에서 직접** 확인합니다.

방법
- 폰을 잠그고 화면을 끈 상태에서 각 경로를 3번씩 실행합니다.
- 결과는 웹 화면 기록 탭이나 시트에서 확인합니다.
- 시험이 끝나면 "시리야, 방금 취소"나 웹 화면에서 시험 기록을 지웁니다.

| 경로 | 잠긴 채 성공 (3회 중) | 잠금 해제를 요구했나 | 시리 응답까지 초 | 메모 |
|---|---|---|---|---|
| 에어팟 + "시리야, 기저귀 소변" | /3 | | | |
| 폰에 대고 "시리야, 수유 상황" | /3 | | | |
| 액션 버튼 (수유 버튼: 시작→끝) | /3 | | | |
| 뒷면 두 번 톡톡 (뒷면 수유 끝) | /3 | | | |
| 잠금화면 컨트롤 버튼 | /3 | | | |
| 워치 시리 "기저귀 소변" | /3 | | | |
| 워치 컴플리케이션 | /3 | | | |
| NFC 스티커 (화면 꺼진 채 / 켜진 채) | /3 | | | |
| 사운드 인식 '아기 울음' (아기 울음 영상 재생으로 시험) | /3 | | | |

**한 번이라도 실패한 경로**는 설계서 1장 표의 예비 경로를 1순위로 올립니다. 결과를 알려주시면 표를 고치겠습니다.

## 6. 기존 Claude 아티팩트 앱

- 6번 `migrate`로 11/18까지의 기록 13건(지운 6건 포함, 숨김 처리)과 설정이 시트로 옮겨집니다.
- 그 뒤로는 **웹 화면(기록 주소)만** 씁니다. 두 곳에 나눠 쓰면 기록이 어긋납니다.
