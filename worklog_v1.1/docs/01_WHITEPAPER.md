# Worklog 백서

## 목적

업무 기록을 한 번 작성하고 프로젝트 현황·주간보고·완료보고에 재사용한다. 사용자가 매일 형식에 맞춰 보고서를 쓰게 하지 않고, 편한 입력 UI와 반복 정보 재사용으로 작성 부담을 낮춘다. 후속 에이전트가 자유 서술을 요약하고 별도 Generator가 PPT를 만든다.

이 시스템은 이메일 수집기가 아니다. 사용자가 브라우저에서 매일 업무일지를 작성한다. 프로젝트별로 기록이 없는 날도 있고 여러 담당자의 기록이 쌓이는 날도 있다.

## 핵심 개념

업무 분류는 **프로젝트 → 마일스톤 → TASK**다. 프로젝트·마일스톤은 기준정보이고 TASK는 해당 날짜에 수행한 일을 기록한 최소 단위다. 행동 하나마다 쪼개는 것을 강제하지 않는다. TASK 마스터·지속적 프로젝트 TASK는 없다.

업무일지는 프로젝트·작성자·날짜별로 여러 TASK와 기타 기록을 담는 그릇이다. 한 일지에 여러 마일스톤의 TASK가 들어갈 수 있다. 같은 일지로 재진입하면 이어 쓴다.

To-Do와 Issue는 프로젝트 단위의 지속적인 관리 대상이다. 매일의 TASK와 상시 연결하지 않는다. Issue에서 대응 To-Do를 선택적으로 만들 수 있다. 완료/해결 시 결과를 일지의 새 TASK로 남길 수 있다.

## MVP 범위

1. 사번(선택)·이름·팀을 설정하는 공통 작성자 선택; 인증 기능 아님.
2. 조직·사용자 기준정보와 Excel/CSV 검증·가져오기.
3. 프로젝트·마일스톤·KPI 기준정보, 단발성 간편 모드, 조직 필터.
4. 리치 텍스트 업무일지, 여러 TASK, 표·체크리스트·간트·이미지/문서 첨부.
5. 정량·정성 성과 프리셋, Lesson Learned·메모·협업자.
6. To-Do/Issue 트래커, 결과 기록, 다시 열기, 이력.
7. 브라우저 초안, SQLite 저장, 수정 충돌 방지·휴지통.
8. 프로젝트/날짜 JSON 자동 생성, 수동 재생성, 백업/복구.
9. 개인 Windows PC에서 수동 실행해 사내망 약 20명이 사용.

## 현재 제외

- 요약 에이전트 실행·PPT 생성·보고서 템플릿 구현·자동 이메일 발송.
- 로그인·SSO·역할 권한·검증된 감사 신원.
- 다중 팀 공동 소유 프로젝트, 동시 실시간 공동 편집.
- 매일 TASK와 To-Do의 지속적인 진행 추적 연결.
- 부팅 시 자동 시작, Windows 서비스, 자동 서버 재시작, 별도 서버 PC 전제.
- 300명 동시 사용 보장, 분산 큐·Redis·별도 작업 서버.
- 사용자 정의 성과 프리셋 관리자, 임의 Excel 서식의 완벽한 재현.

## 원칙

- 사용자 화면은 가벼운 Word/Notion처럼 동작한다. Markdown 문법은 필수가 아니다.
- 문단·표·간트의 편집 가능한 JSON 구조가 본문 원본이다. HTML/Markdown/SVG/PNG는 파생 표현이다.
- SQLite가 서비스 원본이다. `data/json`은 사람이 읽고 후속 도구가 이용하는 재생성 가능한 사본이다.
- 일지는 당시 기록, 트래커는 현재 관리 상태다. 과거 기록을 상태 변경으로 소급 덮어쓰지 않는다.
- 불필요한 빈 섹션·제목·TASK 상태를 강제하지 않는다. 이미지 상세 설명은 보고 재사용을 위해 필수다.
- 표와 간트는 마우스 조작을 제공하되 날짜·셀 구조를 보존한다.
- 데이터 손상·조용한 덮어쓰기·중복 생성을 방지한다. 비용이 큰 운영 기능은 MVP에 넣지 않는다.
- 사용자가 제출한 내용만 보고 근거로 쓰며 에이전트 요약을 원본에 덮어쓰지 않는다.

## 성공 기준

구성원이 프로젝트·마일스톤을 선택하고 업무를 부담 없이 기록할 수 있다. 표·간트·이미지 설명이 저장과 재열기를 거쳐 보존된다. 동일 일지는 이어 쓰고 타 작성자는 독립 기록을 가진다. 트래커와 일지의 분리·선택적 완료 기록이 일관되며, DB와 JSON의 갱신 상태가 식별된다. Windows 수동 실행, 20명 시나리오, 충돌·백업 복구를 실제 검증한다.
