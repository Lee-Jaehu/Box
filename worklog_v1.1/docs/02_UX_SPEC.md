# Worklog UX 명세

## 1. 공통 작성자 설정

최상단에 이름·팀·선택적 사번을 설정한다. 등록된 사용자 선택 후 모든 화면에서 재사용한다. 내부 userId로 구분하고 이름/사번을 키로 쓰지 않는다. 탭 내 화면 이동·새로고침 동안 유지하고 명시적 해제를 제공한다. 구현 기본값은 sessionStorage이며 탭 복원 동작은 브라우저마다 다를 수 있다고 설명한다. 인증·권한 화면처럼 표현하지 않는다.

작성자를 바꾸면 기존 초안의 작성자를 변경하지 않는다. 기존 사용자별 초안을 보관하고 새 사용자의 컨텍스트를 연다. 초안은 사용자 설정 세션 종료와 별도로 보존한다. 모든 팀 데이터 조회·수정이 가능하며 기록의 변경자는 선택된 사용자다.

## 2. 프로젝트 목록·기준정보

- 담당 조직 → 팀, 대표/참여 담당자, 상태, 프로젝트명 검색을 제공한다. 마지막 필터는 브라우저에 기억하고 초기화 가능.
- 프로젝트는 담당 팀 하나; 팀의 상위 담당 조직을 표시한다. 대표 1명과 참여자 여러 명. 작성자는 대표와 다를 수 있다.
- 생성 필수: 이름, 담당 팀, 대표 담당자. ID 자동 생성. 상태 기본 준비.
- 기간, 참여자, 배경·목적, KPI는 상세 입력. 배경·목적은 리치 텍스트 지원.
- 완료 회고는 완료 단계에 선택 작성. 자동 초안은 후속 요약 기능으로 MVP에서 실행하지 않음.
- 프로젝트 복사는 기본정보 재사용 기능. 구현 기본값: 이름 재입력, 상태 준비, 기간/일지/트래커/실적/이력/첨부 제외. 마일스톤·KPI 정의 복사는 선택하고 ID 새로 발급. 원래 기록을 새 프로젝트에 연결하지 않음.

### 단발성 토글

프로젝트명·조직·담당자·상태는 유지. 기간은 마감일 중심, 시작일 추가 가능. 배경·목적은 접음. KPI·마일스톤 상세 관리 기본 숨김. 필요하면 활성화. 기존 값이 있으면 ‘입력됨’ 표시하고 데이터를 삭제하지 않는다. 숨김은 보고 제외를 뜻하지 않는다.

### 마일스톤

Master와 일지 양쪽에서 추가. 일지 빠른 생성은 이름만 필수, 프로젝트 공용으로 저장한 뒤 자동 선택. 기존 유사 이름을 안내하되 자동 병합 금지. 일지 삭제가 마일스톤 삭제를 의미하지 않음.

프로젝트 생성 시 ‘일반·수시 업무’를 자동 생성한다. isGeneral=true, 기간 없음, 실제 일정·완료율에서 제외. 구현 기본값으로 이 항목은 단독 삭제 금지.

계획 시작/종료, 기준 시작/종료, 실제 시작/종료를 선택 관리한다. 기준 일정은 사용자가 확정할 때 저장하며 이후 계획 변경으로 덮어쓰지 않는다. 기준 재확정은 명시적 동작과 이력 필요. 공용 간트에서 막대 이동/크기 변경은 현재 계획을 수정한다. 확정 기준 일정·실제일을 자동 변경하지 않는다. 하루짜리 달성 지점은 같은 시작/종료일, 일정 없는 항목은 일정 미정 목록으로 표시.

## 3. 업무일지

**진입 화면(2026-10-04):** 업무일지 탭은 작성이 아니라 조회로 시작한다. 왼쪽 달력(현재 필터 기준 날짜별 일지 수), 오른쪽 선택한 날의 일지 목록. 상단 필터(범위=내 프로젝트/전체, 담당 조직, 팀, 상태, 이름, 프로젝트, 작성자)는 달력과 목록에 같이 적용된다. ‘업무일지 작성’ → 프로젝트(드롭박스 옆 필터)와 날짜 선택 → 아래 작성 화면. To-Do/Issue 탭도 같은 프로젝트 선택기+필터를 쓴다(날짜 개념 없음).

상단: 작성자, 업무 날짜(오늘 기본), 프로젝트. 프로젝트 화면 진입 시 프로젝트 자동 선택. 실제 생성·수정 시각은 서버가 기록하고 업무 날짜와 구분.

고유 단위는 프로젝트+작성자+날짜. 재진입은 기존 일지 이어 쓰기. 프로젝트 변경 시 초안 보존. 한 일지에는 여러 마일스톤의 TASK가 존재 가능. TASK 입력 카드를 여러 개 열어 오가며 작성할 수 있고 수행 기간 중복 허용.

### 오늘 한 일 카드

- 마일스톤 기본 ‘일반·수시 업무’, 이후 직전 선택 재사용.
- TASK 본문 필수. 별도 제목 필수 아님, 첫 줄은 접힌 카드의 요약으로 사용.
- TASK 상태 없음. 오늘 한 작업을 적는 것이지 관련 프로젝트 전체 완료를 뜻하지 않음.
- 필요할 때 실제 수행일/기간 추가; 기본 업무 날짜. 종료일은 시작일보다 빠를 수 없음.
- 한 카드 안 여러 문단·목록·표·간트 지원. 행동 하나마다 분해 강요 금지.
- 하단 `+ 다른 업무 기록`, 카드 복사·삭제·순서 변경. 복사 시 새 TASK ID, 날짜 재설정, 정식 저장 전 초안.
- Enter는 문서 편집이고 새 TASK 생성 아님.
- 일반 이미지/문서 첨부는 TASK 안에서 추가. 일지 밖 이미지 업로드로 소속 불명 데이터 생성하지 않음.
- 완료·보류·취소 프로젝트도 안내 후 기록 가능(취소는 구현 기본값). 휴지통 프로젝트는 복원 전 새 기록 차단.

### 추가 섹션

필요할 때 To-Do, Issue, 성과, Lesson Learned, 메모, 협업자를 추가한다. 사용하지 않은 섹션에 ‘없음’ 입력 강제 금지. 협업자는 프로젝트 참여자와 별개로 이번 기록 관련자다. 전날의 미완료 To-Do를 일지에 자동 복사하지 않는다.

### 저장·초안

TASK별 서버 저장 버튼 대신 일지 전체 저장. IndexedDB 자동 임시저장(기본 1초 내외 debounce, 구현 조정 가능). 상태는 ‘브라우저 임시저장’과 ‘서버 저장’을 명확히 구별. 초안 키에 서버 인스턴스 ID/사용자/프로젝트/날짜를 포함. 서버 저장 중 새 입력이 생겼다면 이전 저장 응답으로 최신 초안을 지우지 않음. 재접속 복구 후보 표시, 자동 덮어쓰기 금지.

수정 충돌은 내 초안 유지, 최신본 확인·다시 편집/복사 선택. 자동 병합·강제 덮어쓰기 제외. 같은 날짜의 휴지통 일지가 있으면 새 중복 생성보다 복원 안내(구현 기본값).

## 4. 리치 에디터·첨부

버튼 기반 목록/번호/체크리스트, Enter 목록 이어쓰기·빈 항목 Enter 종료, 강조·링크 제공. 기본 표는 마우스로 행열 크기 선택, 셀 입력, 행열 추가·삭제, 열 너비 조절. 셀 병합과 표 붙여넣기는 시제품으로 손실 여부 검증. 최소 보장: 기본 행열·여러 줄·셀 병합의 저장/복원. Excel 완전 서식 호환은 보장하지 않음.

간트는 작업 추가/편집 창, 날짜 선택, 막대 이동·양 끝 조절, 일/주/월 보기. 기간 막대가 핵심. 복잡한 자원 배분·자동 스케줄 최적화·의존 관계 UI는 후속. 공용 간트와 일지 자유 간트는 같은 표현 도구를 쓰되 데이터 소유자는 다름. 일지 자유 간트 수정은 공용 일정에 영향 없음.

체크리스트 체크는 문서 내부 상태일 뿐 프로젝트 To-Do 생성/완료가 아님.

이미지: 선택/드롭/붙여넣기, TASK 자동 연결, 상세 설명 필수, 제목 선택, 순서 변경. 상세 설명 안내: ‘어떤 내용을 보여주며, 보고에서 강조할 점은 무엇인가요?’ 이미지 설명·소속은 사용처에 귀속하여 같은 바이너리 재사용 시 서로 다르게 설명 가능. PPT용 객체는 TASK 본문·마일스톤·캡션·순서를 함께 전달.

일반 문서는 다운로드 첨부, 파일당 20MB. 상세 설명 필수는 이미지에만 적용. 실제 허용 확장자/검증은 운영 명세 참조.

## 5. 성과

성과는 선택 입력. TASK가 ‘활동’이면 성과는 ‘변화/결과’. TASK의 `성과로 정리`는 본문을 초안으로 가져오는 보조 기능(지속적 자동 동기화 아님).

| 정량 프리셋 | 입력 | 계산 |
|---|---|---|
| 시간 단축 | 기존·현재 시간, 단위, 대상 범위 | 차이·단축률 |
| 비용 절감 | 기존·현재 비용, 통화, 동일 비교 기간 | 차이·절감률 |
| 처리량 증가 | 기존·현재 값, 단위·기간 | 증가량·증가율 |
| 오류/불량 감소 | 기존·현재 값, 건수/비율 | 감소량; 비율은 %p 차이 별도 |
| 목표 달성 | 목표·실적·단위 | 두 값 비교, 지표 방향 모르면 달성 판정 금지 |
| 직접 입력 | 지표명·값·단위·설명 | 입력값 |

기존 0이면 변화율 null/계산 불가. 기간·단위 같을 때만 비교. 비율 5%→3%는 2%p 감소, 상대 감소율 40%를 구분. 부호를 숨겨 개선으로 포장하지 않음. 연간 환산은 횟수/기간 등 근거가 있을 때만. 숫자 원본·단위·계산법 버전·표시 문장 보존, 사용자 문장 수정으로 원 숫자 변경 금지.

정량 KPI 연결은 선택: KPI 지표·단위·목표·기준값 가져오기, 이번 측정의 비교값은 확인/변경 가능. 성과 저장이 KPI 실적 자동 덮어쓰기/여러 날 실적 합산을 의미하지 않음. 측정일·대상 기간 보존. 정성 KPI 연결은 MVP 제외.

정성 프리셋은 표준화/체계화, 품질/안정성, 리스크 예방, 협업/의사결정, 사용자 편의, 지식 축적/전파, 직접 작성. 본문 하나와 유형별 회색 안내/하단 도움말. ‘무엇을 했고 무엇이 달라졌는가’를 유도하고 안내 문구는 저장하지 않음. 유형 변경 시 본문 유지. 프리셋 관리 화면 없음.

## 6. To-Do·Issue

화면 이동은 **왼쪽 세로 트리**(Windows 탐색기 왼쪽 창 형태, 2026-10-06, 08 I37 — 상단 탭 대체): `담당 ▸ 팀 ▸ PJT ▸ 전체 Worklog / User(대표·참여자·일지 작성자) ▸ Worklog / 자료 생성기(▸ 주간업무자료, 경영진보고자료)`. PJT를 누르면 오른쪽에 프로젝트 정보, Worklog는 그 과제(User면 그 사람)의 달력+일지 목록과 그 아래 To-Do·Issue 패널(별도 탭 없음), 자료 생성기는 그 과제를 미리 고른 보고자료 화면. 마일스톤 기준 완료 과제는 검회색(+완료 표시), 진행 중은 검정. 트리는 «/» 또는 ☰로 접고 펼 수 있고, 접으면 오른쪽 화면이 넓어진 폭에 맞게 다시 배치된다. 트리 아래 ‘전체 보기·관리’ 묶음: 전체 업무일지, 보고자료(여러 과제·팀장 요약), 프로젝트 목록, 조직·사용자, 운영. 프로젝트 목록 화면은 기준정보 화면이며 일지·트래커 작성은 하지 않는다 (08 I18). 트래커 직접 등록 가능. 내용 필수, 담당자/마감일/영향/대응 선택. 누구나 수정하며 선택 작성자로 이력 기록.

일지에서 첫 서버 저장 시 항목을 트래커에 등록, 이후 재저장으로 중복 등록 금지. 등록 후 일지에는 당시 스냅샷, 현재 상태는 별도 배지/링크. 항목 수정은 트래커에서 수행. 일지 수정·삭제가 현재 항목을 수정·삭제하지 않음.

Issue에서 ‘대응 할 일 추가’ 선택 시 프로젝트와 원본 이슈 자동 연결. 모든 이슈에 할 일 강제 금지. To-Do 완료가 Issue 자동 해결을 뜻하지 않음. 일별 TASK와 지속적으로 연결하는 UI 없음.

완료/해결 창: 결과 한 줄 선택. ‘오늘 한 일에도 남기기’를 선택하면 결과 본문·마일스톤 필요. 날짜 기본 오늘, 작성자 기본 상단 선택 사용자, 저장 전 대상 표시. 같은 프로젝트의 기존 일지에 TASK 추가, 없으면 생성. 일반·수시 업무 선택 가능. 결과 기록과 상태 변경은 함께 저장. 이미지 없는 결과 TASK 허용.

미완료 상태로 다시 열기 가능; 완료 결과·이력·당시 TASK 유지. 재완료는 새 완료 이벤트이며 같은 요청 재전송과 구별. Issue 종결은 해결 확인 단계; 기본 완료 기록 제안은 해결 전환 시, 종결 때 중복 제안하지 않음(구현 기본값).

## 7. 휴지통

프로젝트 삭제는 상위 숨김으로 하위 접근을 막고 하위 행을 모두 개별 삭제 처리하지 않음. 복원 시 원래 활성 하위 기록이 돌아오고, 이전에 개별 삭제된 항목은 삭제 상태 유지. 마일스톤 참조 중 삭제는 기록 보존하고 새 선택에서 제외. 모든 휴지통 자동 영구 삭제 없음. 일반 사용자 영구 삭제 UI는 MVP 제외.
